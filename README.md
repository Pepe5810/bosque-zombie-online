# Bosque Zombie Online — Cooperativo

Juego de supervivencia 3D multijugador. Todos los jugadores comparten el mismo mundo y los mismos zombis: los zombis aparecen por la noche, persiguen al jugador más cercano y pueden atacar a cualquiera. El daño que reciben se comparte entre todos.

## Controles
WASD mover · Espacio saltar · Shift correr · 1-5 armas · Clic izq. atacar/disparar/talar · Clic der. zoom con francotirador · E recoger · B construir · R girar · T subir piso · G pescar · F comer · Enter chat.

## Qué se sincroniza
Jugadores, zombis (posición, vida y muerte), recursos recogidos, árboles talados, construcciones, inventario básico y chat.

## Publicar en Render
Sube el contenido de esta carpeta a GitHub → Web Service Node → Build Command `npm install` → Start Command `npm start`. Usa la URL pública del servicio y compártela con tus amigos.

Nota: el mundo y los zombis se mantienen mientras el servidor está encendido; todavía no hay guardado persistente entre reinicios.
